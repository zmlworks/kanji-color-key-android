<p>漢字色キーは、パスワードマネージャーやディスク暗号化の「最後の鍵」としてよく使われる 256bit の乱数を、一画ごとに 黒・赤・青・緑 の色がついた約8文字の漢字に直し、紙に手で書き写せるようにするアプリです。紙からのデコード（書き付けから鍵に戻す）もでき、自信のない画があっても候補を総当たりで探します。</p>
<p>オフライン Web アプリ <a href="https://zmlworks.github.io/kanji-color-key/">kanji-color-key</a>（方式 v1.1.0）の Android 版です。エンコード・デコードは Java へ移植したもので、Web 版の JavaScript から作った数千件の共通テストベクトルで照合しており、同じ鍵から同じ文字列になります。</p>
<p><b>しくみ</b></p>
<ul>
<li>漢字は決められた 4096 字から1字（12bit）、各画の色が4色（1画 2bit）。</li>
<li>英数字（0・1・8・U を除く32字 × 4色 = 7bit）。記号をタップするとその位置を 漢字⇄英数字 に切り替え。最後は「最後を漢字で」「最後を英数字で」の2案を表示。</li>
<li>任意のチェックビット（SHA-256）と、v1.1 の余剰ビット（最後の余った画などを鍵から決まる色で埋め、チェックとして働く）。v1.0 の黒埋めの書き付けも読めます。</li>
<li>デコードでは <tt>?</tt>（色・英数字が不明）、<tt>(..)</tt>（位置不明のまとまり）、<tt>[..]</tt>（順序入れ替えの可能性）が使え、合う候補をすべて表示します。</li>
<li>鍵は 乱数（SecureRandom）・16進・2進・パスフレーズ（PBKDF2-HMAC-SHA256、60万回）から。データ 64〜512 bit。</li>
</ul>
<p><b>プライバシーと安全</b></p>
<ul>
<li>権限は一切なし（インターネット権限なし）、解析ツールなし、外部ライブラリなし。</li>
<li>既定でスクリーンショットと「最近使ったアプリ」の画面表示を禁止（設定で許可可）。</li>
<li>鍵はストレージに保存せず、バックグラウンドに移ると鍵と入力を消去（設定で切替可）。バックアップ無効。</li>
<li>コピーした鍵は機密扱いの印を付け、60秒後にクリップボードから消去。</li>
</ul>
